Playbook（落地套路）

从一个“小而可控”的 Agent 开始：先做工具调用，再做记忆与多步规划。

推荐路径：① 定义输入/输出与边界 ② 增加工具列表与权限 ③ 加“校验器/约束” ④ 记录执行日志 ⑤ 加重试与回滚 ⑥ 做成本与效果评估。

运行维护

Agent 不是一次性脚本：要考虑失败、超时、限流、数据安全与审计。

常见故障点：外部 API 抖动、网页结构变动、Token 成本飙升、权限过大、并发导致的数据竞争与重复执行。
